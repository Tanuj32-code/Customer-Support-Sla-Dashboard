# Overview
Designed and implemented a **Power BI dashboard** to monitor 500+ tickets across billing, returns, technical, and prime support categories.  
Applied **Python (Pandas, NumPy)** for synthetic data creation and integrated with Power BI for interactive visualization.

# Features
- Ticket volume tracking across categories (Billing, Returns, Technical, Prime)
- SLA compliance % (≈45.80%) and average resolution hours
- Trend analysis of daily SLA performance
- Visual KPIs for quick decision-making

# Tools 
- Power BI (PBIX file)
- Python (Pandas, NumPy for dataset generation)
- Excel (optional preprocessing)

# How to Use
- Download the PBIX file and open in **Power BI Desktop**
- Or view the PDF export for a snapshot of the dashboard
- Run the notebook ('Customer_Support_Queue_Data.ipynb') to regenerate the synthetic dataset

# Business Impact
- Improved SLA visibility
- Reduced escalation delays through automated reporting
- Enabled queue‑level performance insights for billing, returns, technical, and prime support
